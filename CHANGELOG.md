# Changelog

## 1.3.0 — 2026-10-12

- Shorter, more precise descriptions and entrypoints for the five skills; conditional references remain available.
- A design-direction check before implementation and an explicit quality protocol before first delivery.
- A dated comparison of relevant official Anthropic, OpenAI and Google/web.dev recommendations, with original summaries and stated limits.
- Raw conversation removed from the installable/public source; retained in a local private backup. User screenshots are not distributed.
- Robust diagnostics for malformed manifest structures and rejection of private runtime files.
- Deterministic release archives, content/CRC checks, SHA-256 output and tests for disclosure and publication boundaries.
- English public README, Russian guide and contribution instructions. Behavioral and visual results are recorded in the validation report; the presence of a protocol is not a universal first-try guarantee.

- English skill entrypoints, plugin UI and primary release documentation; locale follows the audience.
- Targeted QA guidance for focus after rerender, draft restoration and timezone-consistent dates.
- Community guidelines, private vulnerability reporting instructions, accessibility statement and issue/PR templates.
- Release selection rejects symlinks in both root files and public directories.

## 1.2.0 — 2026-10-10

- Linked creation, redesign, review and professional UI/UX to functional product scenarios.

## 1.1.0 — 2026-10-10
